# Dynamic Keycards

[English version](README.md)

키 카드와 플레이어 귀속 카드 리더기로 만드는 레드스톤 출입 통제.
Minecraft **1.21.1** NeoForge 모드입니다.

![카드 종류: 빈 카드, 키 카드, 매니저/멤버 출입 카드, 골드 키 카드](docs/cards.png)

## 어떤 모드인가

**카드 리더기**를 설치하면 설치한 플레이어에게 귀속됩니다. **빈 카드**를 리더기에
등록하면 키가 찍힌 **키 카드**가 되고, 등록된 카드로 리더기를 사용하면 3초 레드스톤
펄스가 나옵니다. 이게 기본 루프입니다 — 올바른 카드에만 열리는 문, 금고, 기계.

여기에 더해:

- **리더기 4종** — 삽입형·터치형·스와이프형·고급형. 기능은 동일, 외형과 상태등만
  다르며 각각 4가지 시각 상태(대기/허가/거부/등록모드)를 가집니다.
- **분기 복제** — 카드 복제기는 카드를 빈 카드에 복제합니다. 복제본은 *복제 시점에*
  원본이 열 수 있던 곳을 그대로 물려받고, 그 이후 두 카드는 완전히 독립적입니다.
  원격 무효화도, 고아 키 관리도 없습니다.
- **매니저/멤버 출입 카드** — 매니저 카드의 등록은 이 카드로 발급한 모든 멤버
  카드에도 함께 적용됩니다. 매니저를 빈 카드에 복제하면 멤버가, 빈 매니저 카드에
  복제하면 공동 매니저가 발급됩니다. 귀속은 없습니다 — 소지가 곧 권한입니다.
- **골드 키 카드** — 모든 리더기를 통과하고, 남의 리더기에서도 등록모드를 켤 수 있는
  만능 카드 (현재 크리에이티브 전용).
- **카드 단위 관리** — 등록모드에서 한 번의 클릭이 항상 들고 있는 그 카드만
  토글합니다: 통과되는 카드는 해제, 거부되는 카드는 등록. 같은 계열의 다른 카드에는
  영향이 없습니다.
- **소리 피드백** — 통과 = 높은 종소리, 등록 = 밝은 톤, 해제·취소 = 낮은 톤, 거부 =
  낮은 베이스음. 바닐라 노트블록 소리 조합이라 커스텀 음원이 없습니다.
- **염색 재활용** — 아무 카드나 염료와 조합하면 그 색의 빈 카드로 초기화됩니다.

## 연동 (모두 선택 사항)

| 모드 | 제공 기능 |
|---|---|
| **EMI** | 기계 처리 과정을 레시피 카테고리로 표시: 카드 등록(빈 카드/키 카드 → 키 카드, 색상별), 카드 복제(분기/멤버 발급/공동 매니저, 색상별). Create 스타일 레이아웃에 기계가 호버 가능한 촉매로 표시됩니다. |
| **Jade** | 리더기의 소유자·등록모드 상태, 복제기의 복제 대기 상태를 표시합니다. |

**7개 언어** 지원: English, 한국어, 日本語, Deutsch, Español, Nederlands, 中文(简体).

## 진행 상황

| 버전 | 주요 내용 |
|---|---|
| 0.0.1 | 리더기 4종, 16색 키 카드(고유 키), 플레이어 귀속, 레드스톤 펄스, 골드 키 카드, 7개 언어 |
| 0.0.2 | 카드 복제기, 등록 해제, 골드 카드 전체 초기화, 사용 설명서 |
| 0.0.3 | 스냅샷 분기 복제, 카드 단위 등록/해제 토글 |
| 0.0.4 | 매니저/멤버 카드, 공동 매니저, 등록 상한 설정 |
| 0.0.5 | 빈 카드와 키 카드 분리 — 키 유무를 한눈에 |
| 0.0.6 | 카드 이름 정리, 크리에이티브 탭에 전체 아이템 표시 |
| 0.0.7 | EMI 조합법 뷰어 연동 |
| 0.0.8 | 이름 교정, EMI 전 색상 레시피 |
| 0.0.9 | 소리 피드백, Jade 지원, 왕관 매니저 텍스처, 설명 문구 정비 |
| 0.1.0 | 빈 카드 조합법 변경 |

**예정:** JEI 지원, 발전과제, 골드 키 카드의 서바이벌 입수 수단.
